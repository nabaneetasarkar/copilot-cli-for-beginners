# Crawl Level — README

## How This Track Works

### Chain PRs
Each exercise builds on the previous one. You create a new branch from the last
exercise branch, make changes, then open a PR. This creates a chain of
incremental improvements across the 16 exercises.

### Evidence in PRs
Every PR must include **evidence** that the change works — test output, logs,
metrics, or screenshots. This builds the habit of proving your work rather than
just describing it.

### Prompt Usage
Each exercise includes a prompt block. Copy the entire prompt and send it to
Copilot Chat. Copilot will propose a plan and diffs. Review them, apply the
changes, verify they work, then commit and open a PR.
